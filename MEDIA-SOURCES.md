# Exercise media provenance

Source: https://github.com/yuhonas/free-exercise-db

Imported commit: `a859101d633a01c4a1a920d6a8ce41dabba0705f`

Declared upstream license: Unlicense (bundled verbatim). Each catalog ID maps to `exercises/<ID>/0.jpg` and `1.jpg` upstream. Images are copied unmodified. Catalog instructions and names are copied from `dist/exercises.json`.

The app labels these as looping start/end photos, not full-motion videos. Upstream issues have asked about image provenance; independently verify rights before commercial distribution.
